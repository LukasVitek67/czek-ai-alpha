# czek-ai pro VS Code

Chat czek-ai přímo ve VS Code – náhrada vestavěného chatu se stejnými možnostmi:

- **Panel czek-ai** (ikona v levé liště, `Ctrl+Alt+C`): celé rozhraní czek-ai pro otevřenou složku – agent OpenCode s free
  modely, výběr presetu (Web design, Oprava chyby, …), vlastní presety, přepínač pravidel učitele, výběr modelu, historie
  relací. Tlačítkem v liště panelu jde chat otevřít i jako kartu vedle kódu.
- **Z editoru** (pravé tlačítko, `Ctrl+Alt+I`): Zeptat se na výběr, Vysvětlit kód, Opravit s czek-ai (i žárovka u chyby),
  Napsat testy – text s kódem a cestou k souboru se vloží do promptu chatu.
- **Modely czek-ai ve vestavěném chatu VS Code**: ve výběru modelů chatu přibudou *czek-ai Max / High / Low* (nástroje
  agenta VS Code fungují).

Potřebuje běžící appku czek-ai (stejný počítač). Když neběží, panel ji nabídne spustit. Spojení: `%APPDATA%\czek-ai\vscode.json`
(port a token lokálního mostu, jen 127.0.0.1).
